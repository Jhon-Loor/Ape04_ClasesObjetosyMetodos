# Ape04_ClasesObjetosyMetodos

Por medio de este repositorio se mostrará el ejercicio desarrollado en C++ y Java utilizando programación orientada a objetos para el registro de estudiantes y control de calificaciones. El sistema permite ingresar datos, validar notas, calcular promedios y mostrar estudiantes aprobados y reprobados mediante el uso de clases, objetos y métodos.
